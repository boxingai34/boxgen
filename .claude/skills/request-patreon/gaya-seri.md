# Pustaka gaya per seri (Request Patreon)

Bawaannya mengikuti **sumber resmi** karakter: tag artist mangaka atau desainer karakter, ditambah `official art`.

- Tag artist **wajib dicek** di Danbooru sebelum dipakai: `/tags.json?search[name]=<tag>` dan alias-nya. Contoh
  jebakan: `kubo_taito` = 0 post, yang benar `kubo_tite`.
- `post_count` ≥ 50 = kuat. Di bawah 20 = lemah, jadi tambahkan juga deskripsi gaya.
- Pengguna boleh mengganti baris mana pun ("ganti gaya Bleach jadi …"). Untuk satu kartu saja, tulis `Gaya: …` di kartu
  Notion.
